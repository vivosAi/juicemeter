How it works

  1. 01

    An agent on every machine

    juicemeter-agent reads that machine's Claude Code and Codex logins, plus any API keys you point it at, every few minutes.

  2. 02

    Numbers over Tailscale

    Agents share usage on your private Tailscale network. Only numbers travel. Credentials stay where they are.

  3. 03

    Look from anywhere

    The menu bar app, or juicemeter in a terminal, reads every agent and shows one entry per account.

A server only needs the agent. A laptop can run just the app. Anything else can use juicemeter --json.

House rules

  • Read-only. It reads the logins your tools already keep. It never refreshes or rewrites them, so it can't log you out.
  • Zero tokens. Usage numbers only. It never sends a prompt.
  • Credentials stay home. Machines share numbers, never keys.
  • No snooping. No browser cookies, no other apps' data, no Full Disk Access.

Want a provider these rules rule out? There's a ready-made prompt for building it in your own fork.

Install

On every machine you use (you'll need Rust):

git clone https://github.com/vivosAi/juicemeter.git && cd juicemeter
cargo install --path crates/juicemeter-cli
cargo install --path crates/juicemeter-agent
juicemeter-agent install

On the Mac you look from, build the menu bar app:

cargo install tauri-cli --version '^2' --locked
cd crates/juicemeter-app && cargo tauri build --bundles app
cp -R ../../target/release/bundle/macos/juicemeter.app /Applications/

Add your other machines in its settings. Or skip the app and stay in the terminal:

$ juicemeter
